# Spawn documentation

This repository is the publication mirror for Spawn’s Whitepaper and Developer Docs. Canonical authoring currently lives in the private spawn-launchpad repository under whitepaper/ and docs/developers/. Update those sources, run npm run export:gitbook and synchronize this mirror. Do not independently edit mirrored pages in GitBook; bring any editorial changes back to the canonical source before another export.

Keep exactly two document trees. Clearly distinguish implemented features from proposals. Token economics are not finalized. Never claim guaranteed earnings, an unhackable database, completed audits or live custody. Do not add secrets, account data or private application code. GitBook should use free Basic-compatible features only.
