# Economy and token

## One unit across participating games

Spawn proposes a common token for supported activity across its games. Players would deposit that token into the platform, use an account balance for approved actions and withdraw available tokens to a connected wallet.

A common unit could make moving between games simpler. It also ties the platform's obligations together: a faulty reward rule in one game could affect the reserves backing other players. Economic integration therefore requires stronger controls than listing a game or saving progress.

The interface's **PLAY** balance is a demonstration. It is not a chosen ticker, issued token, redeemable claim or a measure of a player's future allocation.

## Utility under consideration

Possible uses include approved in-game purchases and creator-funded rewards. Each use needs a defined source of funds, authorization rules and a clear treatment in the ledger before it can be introduced.

A reward should come from an identified budget or transfer. Changing a number in a save file must never create a withdrawable obligation. If token issuance is allowed in the eventual design, the authority, limits and public reporting must be specified before launch.

See [Using the token](token-flow.md) for the player-facing deposit and spending flow, and [The reward pool](rewards.md) for the proposed funding and distribution process.

## Operating model

Potential revenue sources include hosting or service plans and fees on supported transactions. Pricing has not been selected. The platform needs to measure storage, builds, bandwidth, support and abuse costs before promising free or unlimited use.

Creators operating multiplayer servers would initially bear those infrastructure costs themselves. Shared storage can reduce some setup work without absorbing every cost of running a game.

## Economic validation

A sustainable model needs games people want to play, predictable platform costs and commitments the reserves can meet. Token price appreciation is not a revenue plan or a promised player benefit.

The next economic milestone is a documented accounting model and a funded test environment, followed by explicit decisions on issuance and fees. This whitepaper does not announce a token distribution, fundraising round or investment terms.
